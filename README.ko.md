## Sunsam Code에서 사용하기

기본으로 설정되어 있습니다. 직접 추가하려면(또는 다른 마켓플레이스를 추가하려면):

1. **설정 → MCP 서버 → 마켓플레이스 → 마켓플레이스 추가**.
2. `jhonsu01/marketplace-SunsamCode`(또는 아무 `marketplace.json`의 URL)를 입력합니다.
3. 커넥터에서 **설치**를 클릭합니다. 새 버전이 나오면 **업데이트**가 나타나고 설정은 유지됩니다.

## 다른 앱

같은 `.mcpb` 패키지를 **Claude Desktop**에도 설치할 수 있습니다(더블 클릭). **Codex**와 **DeepSeek Harness**용 Craft 커넥터는 [Craft Bridges 마켓플레이스](https://github.com/jhonsu01/craft-marketplace)에 있습니다.

## 작동 방식

- [`sources.json`](sources.json)은 커넥터 저장소(및 카테고리, 색상, 짧은 설명)를 나열합니다.
- [`scripts/sync.mjs`](scripts/sync.mjs)는 각 저장소의 최신 릴리스를 읽고 `.mcpb`를 내려받아 **SHA-256**을 계산하고, 패키지 안에서 `manifest.json`(버전, 이름, 도구)과 **아이콘**을 꺼냅니다. 의존성 없이 [`marketplace.json`](marketplace.json)과 [`icons/`](icons)를 작성합니다.
- [워크플로](.github/workflows/sync.yml)가 6시간마다, 수동으로, 또는 커넥터가 새 릴리스를 알릴 때 실행합니다:

```bash
gh api repos/jhonsu01/marketplace-SunsamCode/dispatches -f event_type=connector-release
```

- Sunsam Code는 원래 릴리스에서 `.mcpb`를 내려받고 설치 전에 **SHA-256을 검증**합니다.

### 커넥터 추가

저장소를 `sources.json`에 추가하고(GitHub Releases에 `.mcpb`를 게시해야 함) `node scripts/sync.mjs`를 실행하거나 워크플로에 맡기세요.

### 형식

[`marketplace.schema.json`](marketplace.schema.json)을 따르는 `marketplace.json`이면 무엇이든 Sunsam Code 마켓플레이스로 쓸 수 있으므로, 직접 게시할 수도 있습니다.
