## Sunsam Code で使う

既定で設定済みです。手動で追加する（または別のマーケットプレイスを追加する）には：

1. **設定 → MCP サーバー → マーケットプレイス → マーケットプレイスを追加**。
2. `jhonsu01/marketplace-SunsamCode`（または任意の `marketplace.json` の URL）を入力します。
3. コネクターの **インストール** をクリックします。新しいバージョンが出ると **更新** が表示され、設定はそのまま残ります。

## その他のアプリ

同じ `.mcpb` パッケージは **Claude Desktop** にもインストールできます（ダブルクリック）。**Codex** と **DeepSeek Harness** 向けの Craft コネクターは [Craft Bridges マーケットプレイス](https://github.com/jhonsu01/craft-marketplace) にあります。

## 仕組み

- [`sources.json`](sources.json) はコネクターのリポジトリ（とカテゴリー、色、短い説明）を一覧します。
- [`scripts/sync.mjs`](scripts/sync.mjs) は各リポジトリの最新リリースを読み、`.mcpb` をダウンロードして **SHA-256** を計算し、パッケージ内から `manifest.json`（バージョン、名前、ツール）と **アイコン** を取り出します。[`marketplace.json`](marketplace.json) と [`icons/`](icons) を書き出し、依存関係はありません。
- [ワークフロー](.github/workflows/sync.yml) が 6 時間ごと、手動、またはコネクターが新しいリリースを通知したときに実行します：

```bash
gh api repos/jhonsu01/marketplace-SunsamCode/dispatches -f event_type=connector-release
```

- Sunsam Code は元のリリースから `.mcpb` をダウンロードし、インストール前に **SHA-256 を検証** します。

### コネクターを追加する

そのリポジトリを `sources.json` に追加し（GitHub Releases で `.mcpb` を公開している必要があります）、`node scripts/sync.mjs` を実行するか、ワークフローに任せます。

### 形式

[`marketplace.schema.json`](marketplace.schema.json) に従う `marketplace.json` なら、どれでも Sunsam Code のマーケットプレイスとして使えます。自分のものを公開することもできます。
