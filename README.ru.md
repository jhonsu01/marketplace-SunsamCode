## Использование в Sunsam Code

Он настроен по умолчанию. Чтобы добавить его вручную (или добавить другой маркетплейс):

1. **Настройки → MCP-серверы → Маркетплейсы → Добавить маркетплейс**.
2. Введите `jhonsu01/marketplace-SunsamCode` (или URL любого `marketplace.json`).
3. Нажмите **Установить** у коннектора. Когда выходит новая версия, появляется **Обновить**, а ваши настройки сохраняются.

## Другие приложения

Те же пакеты `.mcpb` устанавливаются в **Claude Desktop** (двойной щелчок). Для **Codex** и **DeepSeek Harness** коннекторы Craft есть в [маркетплейсе Craft Bridges](https://github.com/jhonsu01/craft-marketplace).

## Как это работает

- [`sources.json`](sources.json) перечисляет репозитории коннекторов (а также категорию, цвет и краткое описание).
- [`scripts/sync.mjs`](scripts/sync.mjs) читает последний релиз каждого репозитория, скачивает его `.mcpb`, вычисляет **SHA-256** и извлекает из пакета `manifest.json` (версия, имя, инструменты) и **значок**. Записывает [`marketplace.json`](marketplace.json) и [`icons/`](icons) без зависимостей.
- [Workflow](.github/workflows/sync.yml) запускает его каждые 6 часов, вручную или когда коннектор сообщает о новом релизе:

```bash
gh api repos/jhonsu01/marketplace-SunsamCode/dispatches -f event_type=connector-release
```

- Sunsam Code скачивает `.mcpb` из исходного релиза и **проверяет SHA-256** перед установкой.

### Добавить коннектор

Добавьте его репозиторий в `sources.json` (он должен публиковать `.mcpb` в GitHub Releases) и запустите `node scripts/sync.mjs` или дождитесь workflow.

### Формат

Любой `marketplace.json`, соответствующий [`marketplace.schema.json`](marketplace.schema.json), работает как маркетплейс для Sunsam Code, так что можно опубликовать свой.
