## Usar no Sunsam Code

Já vem configurado. Para adicioná-lo manualmente (ou adicionar outro marketplace):

1. **Configurações → Servidores MCP → Marketplaces → Adicionar marketplace**.
2. Digite `jhonsu01/marketplace-SunsamCode` (ou a URL de qualquer `marketplace.json`).
3. Clique em **Instalar** em um conector. Quando sai uma versão nova aparece **Atualizar**, e suas configurações são mantidas.

## Como funciona

- [`sources.json`](sources.json) lista os repositórios dos conectores (mais categoria, cor e descrição curta).
- [`scripts/sync.mjs`](scripts/sync.mjs) lê o último release de cada repo, baixa seu `.mcpb`, calcula o **SHA-256** e extrai de dentro do pacote o `manifest.json` (versão, nome, ferramentas) e o **ícone**. Escreve [`marketplace.json`](marketplace.json) e [`icons/`](icons), sem dependências.
- O [workflow](.github/workflows/sync.yml) o executa a cada 6 horas, manualmente ou quando um conector avisa de um release novo:

```bash
gh api repos/jhonsu01/marketplace-SunsamCode/dispatches -f event_type=connector-release
```

- O Sunsam Code baixa o `.mcpb` do release original e **verifica o SHA-256** antes de instalá-lo.

### Adicionar um conector

Adicione o repositório em `sources.json` (ele precisa publicar um `.mcpb` nos GitHub Releases) e execute `node scripts/sync.mjs`, ou deixe o workflow fazer isso.

### Formato

Qualquer `marketplace.json` que siga [`marketplace.schema.json`](marketplace.schema.json) funciona como marketplace do Sunsam Code: assim você pode publicar o seu.
