## Usarlo en Sunsam Code

Viene configurado por defecto. Para añadirlo a mano (o añadir otro marketplace):

1. **Ajustes → Servidores MCP → Marketplaces → Añadir marketplace**.
2. Escribe `jhonsu01/marketplace-SunsamCode` (o la URL de cualquier `marketplace.json`).
3. Pulsa **Instalar** en un conector. Cuando sale una versión nueva aparece **Actualizar**, y tu configuración se conserva.

## Cómo funciona

- [`sources.json`](sources.json) lista los repositorios de conectores (más categoría, color y descripción corta).
- [`scripts/sync.mjs`](scripts/sync.mjs) lee el último release de cada repo, descarga su `.mcpb`, calcula su **SHA-256** y extrae de dentro del paquete el `manifest.json` (versión, nombre, herramientas) y el **icono**. Escribe [`marketplace.json`](marketplace.json) e [`icons/`](icons), sin dependencias.
- El [workflow](.github/workflows/sync.yml) lo ejecuta cada 6 horas, a mano o cuando un conector avisa de un release nuevo:

```bash
gh api repos/jhonsu01/marketplace-SunsamCode/dispatches -f event_type=connector-release
```

- Sunsam Code descarga el `.mcpb` desde el release original y **comprueba el SHA-256** antes de instalarlo.

### Añadir un conector

Añade su repositorio a `sources.json` (debe publicar un `.mcpb` en sus GitHub Releases) y ejecuta `node scripts/sync.mjs`, o deja que lo haga el workflow.

### Formato

Cualquier `marketplace.json` que siga [`marketplace.schema.json`](marketplace.schema.json) sirve como marketplace para Sunsam Code: así puedes publicar el tuyo.
