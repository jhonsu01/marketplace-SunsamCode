## 在 Sunsam Code 中使用

默认已配置。手动添加（或添加其他插件市场）：

1. **设置 → MCP 服务器 → 插件市场 → 添加插件市场**。
2. 输入 `jhonsu01/marketplace-SunsamCode`（或任意 `marketplace.json` 的 URL）。
3. 在连接器上点击**安装**。有新版本时会出现**更新**，你的设置会被保留。

## 其他应用

同样的 `.mcpb` 安装包也可以在 **Claude Desktop** 中安装（双击即可）。**Codex** 和 **DeepSeek Harness** 用户可在 [Craft Bridges 插件市场](https://github.com/jhonsu01/craft-marketplace) 找到 Craft 连接器。

## 工作原理

- [`sources.json`](sources.json) 列出连接器仓库（以及类别、颜色和简短描述）。
- [`scripts/sync.mjs`](scripts/sync.mjs) 读取每个仓库的最新版本，下载其 `.mcpb`，计算 **SHA-256**，并从安装包内取出 `manifest.json`（版本、名称、工具）和**图标**。它写入 [`marketplace.json`](marketplace.json) 和 [`icons/`](icons)，无任何依赖。
- [工作流](.github/workflows/sync.yml) 每 6 小时运行一次，也可以手动运行，或在连接器发布新版本时触发：

```bash
gh api repos/jhonsu01/marketplace-SunsamCode/dispatches -f event_type=connector-release
```

- Sunsam Code 从原始版本下载 `.mcpb`，并在安装前**校验 SHA-256**。

### 添加连接器

把它的仓库加入 `sources.json`（它必须在 GitHub Releases 中发布 `.mcpb`），然后运行 `node scripts/sync.mjs`，或交给工作流处理。

### 格式

任何符合 [`marketplace.schema.json`](marketplace.schema.json) 的 `marketplace.json` 都可以作为 Sunsam Code 的插件市场，因此你也可以发布自己的市场。
